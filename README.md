# Ban Notes

A simple Python project for recording and viewing player ban information.

**Author:** Meakz  
**Version:** 1.0

### Features
- Add player bans (Name, Steam ID, Notes).
- View saved ban records.
- Stores records in `banlogs.txt`.
- Coloured terminal interface.
  
### Requirements
- Python 3.x
- No additional libraries required.
  
### Files
- `main.py` – Main menu.
- `AddBans.py` – Adds new ban records.
- `ViewBans.py` – Displays saved bans.
- `banlogs.txt` – Stores ban information.

### How To Use

Run main.py.

Select 1 to add a player ban.

Enter the player's name, Steam ID and notes.

Select 2 to view saved bans.

Select 3 to exit.

### Notes
I'm still relatively new to Python, so this is a learning project. Editing and removing records currently requires manually modifying banlogs.txt.
